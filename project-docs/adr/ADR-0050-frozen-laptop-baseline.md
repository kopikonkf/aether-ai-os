# ADR-0050 — Frozen Founder Laptop Baseline

**Status:** Accepted for `v0.19.2-founder-alpha-frozen.1`  
**Date:** 2026-07-29

## Decision

Freeze the Windows-laptop phase into one complete release. The baseline includes only capabilities that are wired and verified in source, plus the Founder-proven embodiment paths from consolidated.1. Future VPS capabilities are not activated here.

## Required changes

1. Telegram approval uses signed inline buttons while preserving exact approval IDs and receipts underneath.
2. Telegram slash commands come from one registry that validates handlers and generates help/menu surfaces.
3. Trust observation time persists across restarts.
4. Windows status evidence uses portable reflection/CIM/environment fallbacks.
5. State inspector v2 covers all known composition-root SQLite authorities and safe behavior state.
6. Original brain is archived inertly; no bulk semantic injection is authorized.
7. Release and wheels are generated from one source tree and checksum manifest.

## Consequences

- Founder interaction is less cumbersome without weakening governance.
- No aspirational Telegram command can appear without a live handler.
- Trust eligibility can accumulate over multiple Gateway restarts.
- The laptop state can be compared deterministically before VPS migration.
- Aether starts a new identity journey while retaining governed access to ancestry later.
