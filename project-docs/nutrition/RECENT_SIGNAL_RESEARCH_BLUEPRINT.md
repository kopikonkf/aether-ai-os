# Recent Signal Research — Aether-Native Nutrition Blueprint

Status: CONFORMANCE BLUEPRINT

## Purpose

Normalize useful ideas from host-oriented recent-window research skills into an Aether-owned capability without directly installing or executing an upstream repository.

The accepted reference disposition remains:

- `last30days-skill` is a nutrition/reference source;
- it is not an active Aether skill;
- exact upstream repository, commit SHA, artifact path, artifact SHA-256, and license must be supplied before a real external nutrition candidate can conform;
- no provenance values are invented in this repository.

## Target capability

`recent-signal-research`

The capability should provide:

1. a bounded recent-window research request;
2. governed adapter selection through `SourceCapabilityMesh`;
3. immutable source snapshots with freshness and provenance;
4. engagement, operational, and economic-signal scoring;
5. contradiction handling across independent sources;
6. bounded synthesis with citations;
7. source-health and conformance receipts.

## Explicitly excluded authority

The normalized capability does not receive:

- arbitrary shell execution;
- unrestricted filesystem access;
- package installation or self-update;
- browser cookie/session extraction;
- credential export;
- private-network access;
- persistent browser profiles;
- arbitrary model-generated JavaScript;
- direct activation authority.

## Intake gate

A real external candidate must declare and pass:

- exact 40-character commit SHA;
- exact artifact SHA-256;
- license and publisher;
- requested source capabilities and exact adapter IDs;
- public network destinations;
- deterministic checks;
- held-out checks;
- Aether normalization target;
- exact passed source-adapter conformance receipts.

A passing nutrition receipt means only:

`eligible_for_benchmark = true`

It never means:

`eligible_for_activation = true`

Activation remains a separate Founder decision through the governed Skill Factory.
