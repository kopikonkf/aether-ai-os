# Factory Source Adaptation

The founder-supplied Factory v1 defines a methodology rather than an implementation. Its retained causal sequence is:

`experience → pattern → concept → belief → prediction → validation → revision`

Aether adopts the following rules directly:

- experience before concept;
- concept before belief;
- belief before prediction;
- prediction before confidence;
- audit before expansion;
- provenance is mandatory;
- decorative modules and vanity metrics are rejected.

Aether extends the source methodology with five executable factories: objective, experiment, capability, business, and evolution. Trading is explicitly one business division, not the global objective or default niche.
