# MVP v0.20 - Governed Shipping + Measured Demand Operations

Date: 2026-07-31
Status: source-present, host-proof pending

## Decision

Promote the release loop above the current runtime body and receipts layer.
The MVP slice is:

validated private experiment
-> consequence impact brief
-> approval
-> deployment adapter
-> public promotion
-> analytics and lead ledger
-> verified demand and revenue linkage
-> rollback / kill switch
-> portfolio reallocation
-> CEE strategy learning

## Runtime Surface

| Surface | Purpose |
|---|---|
| `aether/runtime/mvp20.py` | Build the release packet and render `LASTSTANDINGPOINT.md` |
| `aether-mvp20` | CLI for packet generation and markdown rendering |
| `aether-cloudflare-ingress` | CLI for Cloudflare public probe receipts |
| `/v1/body/mvp20/status` | Read the current release summary |
| `/v1/body/mvp20/packet` | Build and persist a new release packet |
| `LASTSTANDINGPOINT.md` | Canonical handoff artifact for the milestone |
| `$AETHER_HOME/runtime/releases/mvp_v0_20/latest_packet.json` | Latest packet snapshot |
| `$AETHER_HOME/runtime/releases/mvp_v0_20/release_packets.jsonl` | Append-only packet log |
